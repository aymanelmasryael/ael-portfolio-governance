# AEL Portfolio Governance — Changelog

## [1.0.0] — 2026-07-30

### Added
- Governance repository with policies, standards, and templates
- LICENSE-POLICY.md: License classification by asset type
- REPOSITORY-LIFECYCLE.md: Active, Deprecated, Archived lifecycle
- NAMING-CONVENTIONS.md: Repository and file naming rules
- BRANDING.md: Color palette, logo, signature standards
- COMMUNITY-FILES.md: Required and recommended community files
- DECISION-MATRIX.md: Structured decision framework for license, lifecycle, and contradictions
- PORTFOLIO-ARCHITECTURE.md: Four-layer portfolio structure
- CHECKLIST.md: New repository and onboarding checklist
- README templates for engineering and learning repositories
- CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, and ISSUE templates

### Context
This release codifies the policies, standards, and procedures developed across five waves of portfolio modernization (Waves 1–5), transforming a collection of repositories into a governed portfolio.
