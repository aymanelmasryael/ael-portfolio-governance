# AEL Portfolio Governance — Changelog

## [1.0.0] — 2026-07-30

### Added
- Governance repository with policies, standards, and templates
- LICENSE-POLICY.md: License classification by asset type
- REPOSITORY-LIFECYCLE.md: Active, Deprecated, Archived lifecycle
- NAMING-CONVENTIONS.md: Repository and file naming rules
- BRANDING.md: Color palette, logo, signature standards
- COMMUNITY-FILES.md: Required and recommended community files
- DECISION-MATRIX.md: Structured decision framework for license, lifecycle, and contradictions
- PORTFOLIO-ARCHITECTURE.md: Four-layer portfolio structure
- CHECKLIST.md: New repository and onboarding checklist
- README templates for engineering and learning repositories
- CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, and ISSUE templates

### Context
This release codifies the policies, standards, and procedures developed across five waves of portfolio modernization (Waves 1–5), transforming a collection of repositories into a governed portfolio.

## [1.1.0] — 2026-07-30

### Added
- GOVERNANCE.md: Expanded Core Principles (10 principles, up from 5)
- GOVERNANCE.md: Governance Lifecycle — Proposal → Review → Decision → Implementation → Adoption → Periodic Review
- GOVERNANCE.md: Governance Change Criteria — explicit conditions for when a governance change is warranted
- GOVERNANCE.md: Governance Versioning with Patch/Minor/Major levels and examples

### Changed
- Core principle: "Governance evolves by explicit decisions, not by accumulated exceptions" added
- Core principle: "Policies before implementations" added
- Core principle: "Canonical source over duplicated rules" added
- Core principle: "Archive instead of delete" elevated to explicit principle (was implicit in procedure)
- Core principle: "Consistency over convenience" added
- Governance Process: now references the lifecycle stages above it
- Versioning section: expanded from a single paragraph to a full table

### Context
This release turns governance into a self-managing system by defining how governance itself changes. Before v1.1, governance documented decisions. With v1.1, governance also documents how decisions about itself are made — closing the loop on the governance system.
