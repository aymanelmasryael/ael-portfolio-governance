# Community Files Standards

## Required Files

Every public repository MUST include:

| File | Purpose |
|------|---------|
| `README.md` | Project documentation |
| `LICENSE` | License text |
| `.gitignore` | Git ignore rules |

## Recommended Files

| File | Purpose |
|------|---------|
| `CONTRIBUTING.md` | How to contribute |
| `CODE_OF_CONDUCT.md` | Community behavior standards |
| `SECURITY.md` | Security vulnerability reporting |
| `CHANGELOG.md` | Version history |

## CONTRIBUTING.md Template

See [templates/CONTRIBUTING.md](./templates/CONTRIBUTING.md).

## CODE_OF_CONDUCT

All AEL repositories use the [Contributor Covenant](https://www.contributor-covenant.org/) Code of Conduct.

## SECURITY.md

See [templates/SECURITY.md](./templates/SECURITY.md). The security contact should be `info@aymanelmasry.com`.

## CHANGELOG.md

Keep a chronological changelog. Format:

```markdown
## [1.0.0] — 2026-07-30

### Added
- New features

### Fixed
- Bug fixes

### Changed
- Breaking changes
```
