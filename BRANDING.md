# AEL Branding Standards

## Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| AEL Blue | `#0074FF` | Primary accent, links, buttons |
| AEL Violet | `#6C47FF` | Secondary, innovation |
| AEL Teal | `#00D4AA` | Growth, success states |
| AEL Pink | `#FF4D8D` | Energy, action |
| AEL Amber | `#F59E0B` | Warning, warmth |
| AEL Dark | `#030712` | Background (dark theme) |
| AEL Light | `#EEF2FF` | Text on dark backgrounds |

## Logo

The AEL logo is an SVG with blue rectangular blocks forming the AEL mark. It should be included in every repository as `ael-logo.svg` at the root.

## Signature

Standard footer for README and HTML:

```
Built by AEL Digital Studio — ayman@aelstudio.com
```

## Copyright Line

```
© 2026 AEL Digital Studio
```

## Repository Description Format

Standard format for GitHub description:

```
[Project name] — [One-line description of purpose]. Built by Ayman Elmasry — AEL Digital Studio.
```

For example:
```
AEL Image Color Extractor — Extract dominant colors from images. Built by Ayman Elmasry — AEL Digital Studio.
```

## Favicon

For web projects, the AEL logo SVG should be used as a favicon. Inline SVG emoji fallbacks are acceptable for non-visual projects.
