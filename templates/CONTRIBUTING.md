# Contributing

Thank you for your interest in contributing to this project.

## How to Contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/description`
3. Commit your changes with clear messages.
4. Push to your fork and open a Pull Request.

## Guidelines

- Keep changes focused — one logical change per commit.
- Follow the existing code style and conventions.
- Update documentation if your change affects the API or behavior.
- Ensure the project still runs with zero dependencies.

## Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/). All contributors are expected to uphold this code.

## Reporting Issues

Open an issue with a clear description of the problem, steps to reproduce, and expected behavior.
